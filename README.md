## Project Overview
This repository contains the design, complete software environment and simulation framework and evaluation of a custom instruction set architecture "**Risc201**". The project models both 4-stage and 6-stage pipelined microarchitectures driven by a microprogrammed control unit, along with a full toolchain (assembler, dissembler, CLI simulator, debugger, stack preprocessor, stack memory visualizer and ALU class)
